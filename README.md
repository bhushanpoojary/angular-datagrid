# @gridengine/angular-datagrid

Open-source (MIT) Angular data grid — virtualization, sorting, filtering, editing, theming,
and more. Reference spec: [react-open-source-datagrid](https://github.com/bhushanpoojary/react-open-source-datagrid).
See the [delivery plan](https://github.com/bhushanpoojary/gridengine/blob/main/plans/angular-datagrid-plan.md)
for scope and phasing. Demo site: [angular-datagrid-view](https://github.com/bhushanpoojary/angular-datagrid-view)
→ `angular.gridengine.dev`.

This workspace was generated using [Angular CLI](https://github.com/angular/angular-cli) version 22.1.4,
with the publishable library living in `projects/grid`.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
